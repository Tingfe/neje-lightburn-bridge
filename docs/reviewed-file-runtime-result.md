# E54：受限文件作业入口与较长传输验证

2026-10-12。最终目标仍进行中。本轮没有打开串口、连接BLE、执行运动或复位；结果属于软件实现及模拟验证。

已将审阅文件接入BLE/TCP桥接候选。文件执行需SHA-256完全匹配、单独文件/控制授权开关，以及现有初始化/激光隔离开关和新日志；缺少条件或文件发生变化，在创建日志及发现BLE设备之前拒绝。默认只离线审阅，不导入Bleak、不监听端口。一次连接消费一份作业，不自动重连或重放。

当前文件审阅范围为零功率直线X=0..10mm、Y=400、Z/A=0、速度不超过60mm/min，要求M5/S0起始及M5/S0/M2结束、终点X0；不支持通用二维图案、圆弧、非零功率或移动G0。源文件最大4MiB/50,000条命令/512字节每行。硬件前置检查仍要求Idle、零偏移、规定模态及两条空启动块。审阅通过不等于获得新增运动授权。

较长文件不再统一套用45秒作业时限：活动预算=max(45, ceil(估算匀速运动秒数×2+30))，最多3600秒；估算不含加减速、通信和控制。活动时间从首条作业提交开始，暂停期间不累计；控制转换/状态等待仍有独立有界计时。文件模式运行时至多每0.5秒发起一次状态查询，不与未完成状态/私有请求重叠。另有包含暂停的会话总时限，默认活动预算+60秒、上限3660秒；因此暂停不能无限延长会话。

内部$G/G0/$G收尾沿用同一真实终端FIFO，核验终点和模态后才标记完成，内部应答不成为LightBurn发送额度。会话错误、超时、未完成作业被主机取消，以及源已传完但终点未确认即TCP EOF，都会保留失败原因；即使way关闭成功，CLI也不能返回作业成功。控制器已确认的主动取消单独记录，不伪称作业正常完成。
