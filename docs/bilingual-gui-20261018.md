# NEJE Bridge 1.3.0 / build 8：中英双语图形界面

2026-10-18。本轮在 1.2.4 源码上加入中文、英文操作界面。新安装首次启动按 macOS/Python 进程语言选择；已有设备设置而未选择语言的老用户继续默认中文。右上角可随时切换，选项写入原有 `settings.json`，保留设备地址和窗口尺寸。界面标题、按钮、状态、扫描及 LightBurn 配置提示、停止/断连提醒、安全确认和新产生的会话审计文案均随语言切换；已写入的历史日志不改写。协议事件名、GRBL 指令字节、真实设备响应和安全判断不受语言影响。

英文下新建的 LightBurn 条目名为 `LaserLink NEJE5 (BLE Bridge)`。已存在的中文条目沿用原名，避免重复创建或改写用户设备列表。木板设计文件与本次软件改动无关。

本地验证：完整锁定依赖环境下 **470 项全量测试通过**，包含新增的翻译覆盖、语言保存与切换、Supervisor 动态语言、英文设备创建测试。最初用缺少 `bleak` 的宿主 Python 跑全量测试时，实际终止父进程的子进程测试未建立监听；切换到与打包一致的锁定依赖后，该测试单独复跑及全量回归均通过。没有连接设备或加工。另尝试隐藏 Tk 窗口做人工烟测，当前受限执行环境以退出码 134 中止，未取得真实窗口渲染证据。

使用 Python 3.12.15、锁定依赖及项目打包脚本生成 `dist/NEJE-Bridge-1.3.0/NEJE Bridge.app` 和 ZIP，包内离线诊断、arm64 架构、版本、图标、签名验证、内置桥接帮助入口及 ZIP 完整性通过。通过电脑控制工具实际启动了打包 `.app`，看到中文主窗口、语言下拉框、三枚主要按钮和设备状态；取消了启动安全确认，没有开始桥接，随后退出程序。界面检查期间打开了 LightBurn，但未连接机器、提交作业或出光；退出后本机 4002 端口没有桥接监听。电脑控制工具未能可靠操作 Tk 下拉框，因此**英文界面的真实视觉切换尚未确认**，英文路径以自动化离线测试为证。构建元数据中的最低 macOS 版本为 27，反映当前宿主构建环境；该包未在更早系统验证，也未做 Developer ID 签名或 Apple 公证。新包实机 BLE/LightBurn 联调尚未执行；GitHub 云端构建需以[工作流结果](https://github.com/Tingfe/neje-lightburn-bridge/actions/workflows/macos-build.yml)单独核验，不能由本机打包推定通过。
