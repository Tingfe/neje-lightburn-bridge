# 下一步：1 mm 无激光运动对照方案（已授权并执行，结果另见报告）

依据当前 USB/BLE 一致的真实读取：$130=260 mm、$131=400 mm，机器报告 MPos X=0、Y=400；$G 为 G21/G90/G54/M5/S0，$# 坐标偏移均 0。激光模组仍以此前现场确认的物理隔离为前提，软件没有测量隔离状态。

需要现场确认 X 正向 1 mm 无障碍、无人接触运动部件，并允许设备实际运动。不能从这些设置或软件状态推断物理现场安全。

建议先用 USB、再用 Mac 原生 BLE，各执行一次同样的固定序列：

```gcode
G53 G1 X1.000 F60.000
G53 G1 X0.000 F60.000
G0
```

前两条使用机器坐标，只动 X 轴，在 0–1 mm 区间往返，进给 60 mm/min。最后仅恢复 G0 模态；进给值会保留为 F60，这个状态变化必须记录。没有 Y/Z/旋转轴指令，没有 M3/M4、S、回零、解锁、复位或设置写入。

每条运动前核对同一设备、真实 Idle/M5/S0/G21/G90、行程、MPos 起点及坐标偏移；读取条件与当前基线不符就拒绝发送，不猜测起点。收到真实 ok 后仍需轮询 Idle 与 MPos 终点，因为 ok 不能代替运动完成。任意超时、报警、断链或计数异常即停止追加指令，记录结果不确定，不自动重发、不自动尝试返程。

此实验依赖现场人员可独立断电停止设备，不能把待验证的 BLE 急停当作唯一停机手段。当前 $20/$21=0，软件/硬限位均未启用，更不能靠限位替代现场确认。

通过后再开放 LightBurn 的小作业原始指令流，独立验证持续流控、暂停/取消和真实加工结果。1 mm 对照成功不会被标记为最终目标完成。

用户两次现场授权及实际结果见 [运动报告](one-mm-motion-result.md)。首次 USB 前进后的脚本解析错误触发停止，后续返程经过单独确认；未自动返程或重复前进。
