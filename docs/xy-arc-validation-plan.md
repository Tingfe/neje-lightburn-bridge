# 圆弧候选后续验证范围（E58历史方案）

2026-10-13 E76更新：下文为E58当时的范围。用户现已持续允许有效行程内零功率移动，旧待授权描述不再作为当前门槛。Mac锁屏期间已按[USB圆弧基线方案](usb-arc-baseline-plan.md)完成手工协议文件USB实测，见[结果](usb-arc-rapid-baseline-result.md)；这一步明确不计原生LightBurn导出或BLE圆弧验收，完整目标仍保留。

本轮只完成[离线结果](xy-arc-result.md)。默认命令不连接硬件；不得因存在执行开关或旧直线授权而运行圆弧。当前优先完成真实LightBurn二维导出和已提出的运动停止验证，避免增加重复现场问题。

后续圆弧实机实验须先固化真实LightBurn导出文件、SHA及完整路径，核实与实际设备坐标、行程和模态一致，再形成一次明确的USB/BLE作业范围及现场确认。手工模拟文件不能冒充原生导出。LightBurn优化器可能改变切入点或插入移动G0；现有候选对此会拒绝，不能改写原文件或伪造应答消除拒绝。

准备阶段只读核对Idle/X0/Y400、零偏置、毫米/绝对/每分钟进给、M5/S0、启动块空及实际设置。第一次曲线对照需要激光物理隔离、完整XY路径净空、现场观察和独立断电条件；授权应指向具体文件、两路次数和完整包围盒。现有示例整圆包围盒为X0..20/Y370..400，超出此前只动X轴的范围。

执行时按原字节传输，同时保留原始TX/RX、CRC/计数、公开终端/私有收尾归属、状态与清理证据；USB/BLE分别审计。现场需确认曲线、方向、完整返回及无其他轴异常/出光，不能只检查终点。任何错误或不确定传输均停止新提交，不重发、不自动返程、回零、解锁或续跑。无意外断连记录时，不宣称断连验收通过。

上游GRBL与NEJE固件可能存在数值和插补差异。解析圆弧边界是审阅依据，未测量实际插补误差；如实机响应或路径不一致，保留失败证据并收紧支持范围。实际加工需另行完成材料、功率及USB对照，不由本零功率范围包含。
