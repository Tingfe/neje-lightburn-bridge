## 新入口的行为

`tools/lightburn_session.py recover`默认离线，不创建会话或连接设备。实际执行只针对同一根目录指向的故障或失去拥有者的running会话；需取得真实进程锁，校验session目录及ID、原始通知/帧、保留写入与设备计数，且匹配记录的BLE地址。普通桥接增加目标地址日志，不改变命令白名单或传输方式。

复用已有检查/关闭实现：唯一同地址NEJE 5 Plus、model55/app3、way0或所属way2、零收发错误、写计数处于最后核验点或最后一个不确定GATT块全部接受处，读变化不超过1024字节。连续三次状态稳定后，至多关闭一次并读回way0/app3和不变计数。范围不符就失败，不接管未知路由。

只有实际接受字节落在完整GRBL行边界，才建立另一次受限读取连接，精确执行 `? / $$ / $G / $# / $N / ?`。独立核验两次Idle/X0/Y400/Z/A0/FS0,0、M5/S0、毫米/绝对/G54、零偏移、260×400行程和空启动块，以及CRC/计数/真实响应和关闭，才将顶层状态改为recovered，允许随后另行start。

原故障session.json及bridge.jsonl不修改，原作业不追认为完成。半行、已有复位导致位置不可信、计数不明、非零功率、非预期位置、损坏/半行日志或活动拥有者均不能由此入口解除阻止；本版不自动补换行、复位、回零或续跑。允许的读取顺序和X0/Y400基准是当前验证范围，不代表任意故障、任意位置都已恢复。
