## 已有的关键实证

- LightBurn 经本项目桥接完成图片实际加工，用户确认 Stop 可用；该图片会话的首段 4,638 条可执行 GCode 与离线导出一致，控制器返回真实 `ok`。旧工程曾出现预览 `0:00`、点击 Start 无作业提交的问题，已保留失败记录和恢复副本。[图片故障与复测](image-job-no-start-20261015.md)
- 2026-10-18 小房子切割约 58 分钟，用户确认作业和成品完成；捕获中 1,341 条入队命令均有真实 `ok`、末尾 `M2` 确认、最终 `Idle`。其后 BLE 断开，清理未确认，所以不能称整个会话完全无故障。[长时实切](house-cut-long-run-20261018.md)
- 早期 USB/BLE 同源作业做过命令和轨迹对照，并有尺寸现场测量；它不代替目前这座小房子的同条件成品对照。[USB/BLE 对照](usb-parity-goal.md)
- [v1.3.0 正式 Release](https://github.com/Tingfe/neje-lightburn-bridge/releases/tag/v1.3.0) 已发布，云端 arm64 包校验通过；用户确认已验证 1.3.0。双语功能有自动化测试，云端 ZIP 的中文主窗口已打开。用户实测的具体项目、英文界面视觉切换及此云端 ZIP 的 BLE/LightBurn 路径尚未逐项记录，不把它们计为独立验收。[发布核验](release-v1.3.0-20261021.md) · [双语实现](bilingual-gui-20261018.md)

## 还差什么

1. **回退后的完整使用复测**：现已实测 2.3.2 的状态帧、关闭读回和 LightBurn 初始化；还需在现场条件具备时复测图形包启动、正常断开/重连及实际作业。2.4.0 的协议适配仍是独立兼容性问题。[回退验收](firmware-rollback-decision-20261019.md)
2. **断连收尾**：解释或修复小房子作业结束后的 BLE 断连及 `cleanup_unknown`；复测正常断开、Stop 后回零和再次连接时的真实状态。
3. **成品对照**：若要宣称完整 USB 等效，在同一设计、材料、对焦与参数下分别经 USB/BLE 加工，量尺寸、记录质量及过程。不为提高分数而无必要地重复加工。
4. **新版实包记录**：v1.3.0 已发布且用户确认做过验证；后续补记其具体使用场景、英文界面视觉切换和这份云端 ZIP 的 BLE/LightBurn 实机路径。构建成功只证明包生成，不替代硬件证据。

新增的气辅自动控制属于扩展功能，[方案已写](neje5-auto-air-assist-20261018.md)，但尚无本机 M8 接口及阀动作验收；它没有计入现有 96 分。

工程证据分为源码/离线测试、应用包、真实通信、控制器状态、现场机械观察和成品测量；各层不能互相替代。更早的 P0–P4、轮次记录和旧百分比见[文档索引](README.md)，不再作为当前使用说明。
