## 已有的关键实证

- LightBurn 经本项目桥接完成图片实际加工，用户确认 Stop 可用；该图片会话的首段 4,638 条可执行 GCode 与离线导出一致，控制器返回真实 `ok`。旧工程曾出现预览 `0:00`、点击 Start 无作业提交的问题，已保留失败记录和恢复副本。[图片故障与复测](image-job-no-start-20261015.md)
- 2026-10-18 小房子切割约 58 分钟，用户确认作业和成品完成；捕获中 1,341 条入队命令均有真实 `ok`、末尾 `M2` 确认、最终 `Idle`。其后 BLE 断开，清理未确认，所以不能称整个会话完全无故障。[长时实切](house-cut-long-run-20261018.md)
- 早期 USB/BLE 同源作业做过命令和轨迹对照，并有尺寸现场测量；它不代替目前这座小房子的同条件成品对照。[USB/BLE 对照](usb-parity-goal.md)
- 1.3.0/build8 中英双语源码已推送；本机 arm64 包、470 项离线回归、GitHub 测试及打包工作流通过。英文界面的真实视觉切换、新包 BLE/LightBurn 实机使用和正式 Release 仍应单独核验。正式 Release 在 2026-10-18 核查时仍为 1.2.4。[双语包与 CI](bilingual-gui-20261018.md)

## 还差什么

1. **断连收尾**：解释或修复小房子作业结束后的 BLE 断连及 `cleanup_unknown`；复测正常断开、Stop 后回零和再次连接时的真实状态。
2. **成品对照**：若要宣称完整 USB 等效，在同一设计、材料、对焦与参数下分别经 USB/BLE 加工，量尺寸、记录质量及过程。不为提高分数而无必要地重复加工。
3. **发布验收**：在 1.3.0 实包中确认英文界面切换和真实 BLE/LightBurn 工作，再决定正式 Release。构建成功只证明包生成，不证明新包的硬件路径。

新增的气辅自动控制属于扩展功能，[方案已写](neje5-auto-air-assist-20261018.md)，但尚无本机 M8 接口及阀动作验收；它没有计入现有 96 分。

工程证据分为源码/离线测试、应用包、真实通信、控制器状态、现场机械观察和成品测量；各层不能互相替代。更早的 P0–P4、轮次记录和旧百分比见[文档索引](README.md)，不再作为当前使用说明。
