## 3. 安全设计（新增能力必须满足的最低要求）

1. **功率必须被声明并强制**：新 profile 形如 `xy-linear-power`，审阅时接受 `0 < S <= S_max_declared`，其中 `S_max_declared` 由本次授权显式给出（例如 `$30=1000` 下的 `S<=100`）。任何超出、缺失或重复的 `S` 一律拒绝。
2. **进给上限**：仍强制 `F <= F_max_declared`；G0 沿用既有规则（不受 F 限制，但必须单独声明并核验真实速度/加速度配置）。
3. **几何包络**：沿用按包围盒判定（含圆弧解析极值），越界拒绝。
4. **前后缀不变**：仍强制 `M5`/`S0` 开头与 `M5`/`S0`/`M2` 结尾，保证失联后不会残留带功率的模态。
5. **摘要锁定**：源文件 SHA-256 与运行时二次校验保持；启动前重新读取真实速度/加速度并要求匹配。
6. **独立审计不变**：真实终端应答、终点/模态/私有收尾、`way=0`/`app3` 关闭、`no_synthetic_ack`/`no_replay` 全部保留；功率相关字段进入审计输出。
7. **现场门槛**（每一项都必须由用户在当次会话前逐条确认）：
   - 激光供电**解除物理隔离**的明确确认，且仅限本次；
   - 材料已就位、固定、无异物；
   - 佩戴与波长匹配的护目镜；区域净空、无人触碰；
   - 通风/排烟与灭火器材就位；
   - **现场可独立切断**设备/电机/激光供电，且操作者不等待软件结果；
   - 明确「BLE 或 TCP 断开不等于激光停止，失联时已缓冲动作可能继续」。
8. **不新增白名单、不写设备设置**：`$n=value` 写设置仍被拒；功率只通过 GCode 的 `S` 表达。

## 4. 分阶段验证计划

每阶段都必须：摘要锁定 → 实时预检 → 执行一次 → 独立审计 → 现场观察另记 → 失败原样保留、不追认、不自动重跑。

### Phase 1：极小功率单段（USB 先，BLE 后）
- 内容：`M5/S0` → 移动到起点 → `M4` 或 `S<极小值>` 沿 10mm 单段 → `M5/S0/M2`。
- 目的：先证明**真的能出光**、能被观察到、能被安全终止；比较同文件 USB 与 BLE 的刻痕位置与外观。
- 门槛：`S` 取当前授权的最小可用值；现场逐条确认；单次单段。
- 通过判据：两路刻痕位置一致、无异常、无失控；审计通过；现场观察记录。

### Phase 2：二维闭合轮廓（小功率）
- 内容：10×10mm 闭合正方形，低功率、低速度。
- 目的：验证二维加工路径与 USB/BLE 一致性。
- 通过判据：两路成品尺寸/位置一致（**需独立测量**，不再只靠肉眼），审计与关闭通过。

### Phase 3：完整加工件对照
- 内容：一件真实图形，同材料同参数，USB 与 BLE 各一次。
- 目的：完成本项验收。
- 通过判据：成品达到「与 USB 连接一样的使用效果」的**可对照结论**（由用户判定），并保留全部原始捕获与照片证据。

### 2026-10-13 模组规格核实（NEJE A40640）与由此产生的冲突

用户确认激光器为 **NEJE A40640**。官方资料（[NEJE.WIKI 模块-A40640](https://neje.wiki/doku.php?id=cn:nejelaser_cn_a40640)）要点：波长 **455nm**；模块功率标注 **40W**（[店铺页](https://neje.shop/collections/diode-laser-engravers-cutters/products/40w-laser-module-laser-head-for-cnc-laser-cutter-engraver-woodworking-machine) 标题写 12W，**官方自身命名不一致，两者均记录**）；宣称「**2000mm/min 不锈钢表面标记**」与「500mm/min 深色雕刻」，不锈钢深色雕刻参数为 **功率 100%**；切割能力「最大 20mm」**仅针对轻质木材**，**无金属切割宣称**；变焦模块，官方强调对焦的重要性。

**冲突（必须先解决）**：

1. 「金属 2mm 切割」与官方能力不符，不成立。
2. **「Phase 1 用 S≤50（5%）」与「金属标记」互斥** —— 官方金属标记参数为 100% 功率，5% 在金属上极可能不留下任何痕迹，导致 Phase 1 既不能证明出光也不能证明无出光。
3. 变焦未对焦时任何功率都可能无痕。

**建议**：Phase 1 改用低功率即可显痕的基材（纸/卡纸/木片/黑纸/涂层画布）并保持 `S≤50`；Phase 2/3 再上金属标记，并把封顶按级抬到厂家参数所需水平。
