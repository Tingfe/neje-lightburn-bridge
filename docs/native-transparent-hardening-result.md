## 验证结果

- 完整本机回归：419项、76.344秒、全部通过。无私有证据的源码副本：262项、45.905秒，27项明确跳过，235项实际执行；上一审查为173项/34项模块跳过。共用假BLE fixture已从私有捕获测试中分离。没有声明远程GitHub CI本轮通过。
- 六组可重现离线实际回环：初始化、TCP复位、当前所属连接停止、原生点动/取消、慢应答及接受写入后失联。五组完整审计通过；失联组正确拒绝通过、保留不确定写计数/未知清理，无重放。这些是模拟，未接真实BLE。
- 新审计反例：删除全部交付、全体计数错位100、篡改原始通知、虚构返回、删除确认、失败/未知清理及开放捕获，均不获完整通过。初次扩大历史尾帧检查使七项旧捕获测试失败，失败输出保留在tests-intermediate.txt；旧完整响应/计数仍核验，历史未完成系统信息尾帧如实报告，新透明会话要求零原始尾残留。
- 两次真实LightBurn初始化候选会话。第二次以native_transparent标识，读取$G，并在Idle/M5/S0条件下发送一次~：实际输入和写出均一次，随后仍Idle/X48/Y245。没有启动作业，未发送轴运动、出光、设置写入、回零或复位指令。初始化只包含裸G0、$I/$#、空行、状态及$G查询。
- 第二份真实捕获完整严格审计通过：设备10366字节，公开回传10288字节；其余为私有基线响应。CRC/原始帧/连续计数/终端归属/公开交付均核验，原始尾残留0，way=0/app3、failure_reason=null。结束时recent-Idle门槛满足。LightBurn现有未保存图稿与设备配置保留，验证服务正常关闭。
- 初始化后增加的长应答兼容与打包模式检查改动完成离线验证；未把这次初始化称作这些新增行为的实机验收。当前透明运动Stop/点动及BLE数小时运行仍待验证。
- 新候选CLI：dist/transparent-hardening-20261014/neje，约9.3MiB；--help、--test --dry-run --valid-for 2、内置模式检查--help均退出0，不扫描或连接BLE。候选.app与CLI二进制摘要一致；它是Terminal包装，不是Tk GUI成品。
