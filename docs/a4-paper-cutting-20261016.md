# 70–80 g/m² 普通 A4 纸试切记录（2026-10-16）

## 现场反馈

用户在 NEJE 5 Plus / A40640 上试切常规 70 g/m² 或 80 g/m² A4 纸。用户确认 **2500 mm/min、100% 功率、单遍、未开气辅**时边缘干净、没有明火，并反馈如下；3000 与 2700 两档按同功率、单遍比较理解，未核对 LightBurn 图层截图，也未区分实际用的是 70 g/m² 还是 80 g/m²：

| 速度 | 现场观察 |
| ---: | --- |
| 3000 mm/min | 效果基本达到预期，但单遍后部分位置仍有连接，未完全切断 |
| 2700 mm/min | 几乎切透，仍有少量连接 |
| 2500 mm/min | 基本完全切透，当前最接近可用的单遍试切值 |

因此不能把先前的 3000 mm/min 记作“单遍切透”。2500 mm/min、100%、单遍、无气辅可作为**这批纸、当前焦点和摆放条件下的候选值**；用户已确认小样边缘干净、无明火，尚无多张连续切割时完全切透率与边缘一致性的记录。此条是用户现场反馈，未由原始会话、照片或尺寸测量独立核验，也不是所有 70–80 g 纸张可直接套用的通用配方。

## 参考与使用边界

- [NEJE 5 Plus 官方示例](https://neje.wiki/doku.php?id=cn:nejelaser_cn_howto_install_n5_plus_cn)给出 A40640 **纸板**切割 6000 mm/min、100%、1 遍；纸板与复印纸不同，不能把这组数值当成复印纸验收参数。
- [LightBurn 材料测试](https://docs.lightburnsoftware.com/2.2/Reference/MaterialTest/)建议在实际材料上比较速度、功率与遍数，选择能够稳定切透且边缘焦黄最少的组合。找到重复有效的参数后，才适合保存到[材料库](https://docs.lightburnsoftware.com/latest/Reference/MaterialLibrary/)。
- 若希望少焦黄，可围绕 2500 mm/min 做更细的小样：保持功率、焦点和遍数不变，在 2500–2700 mm/min 间细调；也可固定 2500 mm/min 降低功率，一次只改一个变量，以“小样完全切透、边缘干净”为判据。务必核对 LightBurn 速度单位，固定薄纸并全程看守；纸张容易移位和起火。
