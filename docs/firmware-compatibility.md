# 固件兼容性

适用对象：本项目 **NEJE Bridge → NEJE 5 Plus → LightBurn** 蓝牙透明桥接。以下结论来自一台 Verify model 55、主板硬件 2.0.1 的设备，不能推广到所有 NEJE 机器或所有固件。

| 设备的 System / NEJE / GRBL 分项版本 | 本项目的实测结果 | 使用判断 |
| --- | --- | --- |
| **2.3.2 / 2.3.2 / 2.3.2** | 曾经完成图片、矢量及约 58 分钟小房子实切。2026-10-19 从 2.4.0 回退并完整断电重启后，USB、BLE 可靠通道和真实 LightBurn 初始化再次通过；回退后尚未重新加工。 | **本机实测支持的版本组合**；使用前仍需确认设备处于 GRBL 模式、桥接收到真实回复。 |
| **2.4.0 / 2.4.0 / 2.4.0**（Windows NEJE Neo 显示 `v3.0.0 调试版3`） | USB GRBL 和 NEJE 原生蓝牙可用，但本项目依赖的 BLE GRBL `0x40` 状态查询多次无回复，桥接无法初始化。 | **本机当前桥接协议未通过**；不能凭 USB 或 NEJE 客户端正常连接推断 LightBurn 蓝牙桥接可用。 |
| 其他版本或混合分项 | 未验证。 | 先核实三项真实版本及通道响应，不推定兼容。 |

Neo 的 `v3.0.0 调试版3` 是固件**包标签**，Windows Neo `v7.0.0` 是**上位机版本**；它们都不是三个分项的版本号。本机在该包下的 System/NEJE/GRBL 实读均为 2.4.0。Mac 桥接源码和 1.3.0 图形包尚无对 2.4.0 的实机兼容性证明。

核对版本时，不要只看 USB `$I`：它只报告 GRBL 应用版本。源码使用者可先关闭桥接及其他 NEJE 客户端，再运行 `python3 tools/p0_probe.py --query`；日志中的 `app_info.apps` 分别给出 ID 1（System）、2（NEJE）、3（GRBL）的真实版本。此命令只发送 Verify 和 SystemRead，不开启 GRBL 通道；普通用户可保存官方客户端的完整版本信息供核对。若三项无法确认，就按“未验证”处理。

**使用前：**若依赖本项目连接 LightBurn，先确认设备的三项固件版本；升级固件前备份 GRBL 设置。连接失败时保留桥接日志与固件版本，勿反复点击 Start，也不要绕过无应答的状态检查。若考虑回退，只使用与设备匹配的 NEJE 官方更新界面，并先阅读[本机回退过程和验收](firmware-rollback-decision-20261019.md)；这份记录不是通用刷机教程。

原始诊断见[2.4.0 失答记录](connection-init-race-20261019.md)。2.4.0 的协议变化或失答根因仍未确定；一台设备的结果不足以断言所有 2.4.0 固件都不兼容。
