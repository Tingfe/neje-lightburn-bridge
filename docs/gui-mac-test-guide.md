# NEJE Bridge 1.2.3 图形版测试指南

> 本文记录 1.2.3 现场测试流程。当前 1.3.0 中英双语包的新增内容、验证范围和本机路径见[双语版本记录](bilingual-gui-20261018.md)。

2026-10-15，build 6。本机软件测试包：LightBurn → TCP `127.0.0.1:4002` → Mac BLE → NEJE 5 Plus。透明转发，不要求审阅作业文件，不改写 GCode，不伪造设备成功响应。用户已反馈修正图片可以加工、Stop 正常；1.2.3保留紧凑布局及新图标、1.2.2的回零等待修正，并增加正常断开后的继续待命。两项新版行为尚待独立实机验收。

## 日常启动

1. 双击 `dist/NEJE-Bridge-1.2.3/NEJE Bridge.app`，或解压同目录 ZIP 后打开。包内包含 Python、Tcl/Tk 和 BLE 依赖，不用 Terminal。若旧版仍在运行，先确认其当前作业状态，再由操作者正常关闭旧版；不要同时启动两个桥接监听。
2. NEJE 上电、处于 GRBL 模式，结束其他占用本机 4002 端口的桥接。第一次启动自动扫描；唯一 NEJE 自动选用，多台时展开“设备与测试选项”选择。以后记住设备名及地址。
3. 点击“启动桥接”，首次完整启动确认现场条件，本次应用运行中不重复确认。**有效期默认到程序退出**，没有小时数设置；退出后关闭所属子进程和监听。不会保存现场条件确认。
4. 点击“创建 LightBurn 设备”或“打开 LightBurn”。新建时先手动保存并退出 LightBurn；程序会备份配置、直接建立可选择的原生 GRBL/TCP 条目并打开 LightBurn。已有本机 4002 条目则直接打开，不修改原设备、不关闭未保存工程。
5. 在 LightBurn 选择 **LaserLink NEJE5 (蓝牙桥接)**：GRBL/Ethernet-TCP、127.0.0.1、4002；260×400mm、左前原点、S 最大值1000、关闭自动回零、空开始/结束脚本。看到真实版本、状态回应及 Ready 后才算连接。

日常界面将启动/关闭桥接、打开/创建设备、软件停止并排放置；设备选项与运行记录默认收起。设备不在旁边时可打开界面、创建配置、调整设计和预览，但不能完成真实连接验收。

当前本机包为 **Apple Silicon / arm64**，最低 macOS 版本以本次构建元数据为准，使用 ad-hoc 签名，没有 Developer ID、公证或其他 Mac 验收。若系统阻止打开，保留提示反馈，不关闭系统保护。旧包验证保留为历史证据，不能替代新版实机验收。

修正工程保存在 `evidence/gui-ease-20261014/user-image-corrected.lbrn2`，原 PNG 未修改，工程保留用户放置的两个图片对象。该工程原有 **6000mm/min、20%功率、气辅开启**，不是零功率测试文件。2026-10-14 的诊断只预览和模拟传输；2026-10-15 用户随后报告图片可加工、Stop 正常，原始会话核对见[现场反馈](gui-polish-20261015.md)。参数效果仍需按材料、对焦及设备条件确认。

“负片图像”在图层的切割设置编辑器中。预览窗口的“反转”仅改变显示背景，不能修复空作业。普通黑色图或照片不应套用这张白色标志的负片设置。LightBurn 原生图像栅格会生成 G0/G1/S 扫描行，桥接按原字节转发。

## 停止、关闭及故障

LightBurn Stop 和“软件停止设备”通过当前所属 BLE 链路发送 GRBL 复位 `0x18`。请求提交、真实横幅/新状态确认、现场机械停止是三个不同结果。复位结束旧作业账本、废弃未发送内容，保留健康连接以接受新初始化，**不会自动解锁、回零、返程或重放**。

“关闭桥接”和退出应用只关闭连接，已经缓冲的动作可能继续。LightBurn 正常断开后，只有真实 Idle/FS:0,0 与清理、审计均通过，图形程序才自动准备新连接；曾发生 Stop 仍需操作者确认或重建坐标。无线断连、缺少真实复位确认、运行中断开或清理未知仍作为故障处理，不自动续传；检查设备后显式“重新连接”。软件停止未确认时独立断电。

后续完整验收还包括相对点动/点动取消、暂停恢复、受控 BLE 断连后的清理和显式恢复、当前透明 BLE 数小时运行，以及同材料同对焦的 USB/BLE 加工对照。既有普通移动授权持续适用；物理结果仍需现场观察和成品测量。
