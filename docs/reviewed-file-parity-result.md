# E55：同文件USB/BLE候选与在途断连模拟

2026-10-12。本轮完成USB变长文件入口及两种BLE作业故障模拟；没有打开串口、连接BLE、运动、出光或复位。最终目标仍进行中，整体估算保持约60%。

## 实现

`controlled_usb_probe.py --job-file`使用与BLE候选相同的文件审阅、SHA-256锁定、前置设置/模态/偏移检查、空启动块读取，以及控制器终点/$G/G0/$G/最终Idle收尾。运行必须指定文件摘要、单独文件/控制授权、隔离确认和新日志；缺少条件、摘要错误、混用固定运动/运动取消范围，在创建日志及导入串口模块前拒绝。默认只离线输出审阅信息。

USB底层按审阅文件原始命令字节逐段核对，部分写失败即锁住旧会话、不重发。文件模式目前只允许正常完成，底层也拒绝!/~及0x18；固定作业控制实验仍使用原有独立范围。USB文件发送改为有界增量入队，作业暂存不超过16KiB，流水普通队列另有16KiB上限，实际在途行数和字符额度沿用现有核心。活动预算与BLE文件入口一致，总时限为活动预算+60秒。

BLE桥接现在保留最初的传输失败原因：数据块接受后断连时，后续“无法确认设备关闭”异常不会覆盖首个错误。主机本地队列废弃与设备是否停止/通道是否关闭继续分别记录；关闭未确认仍使CLI失败，不自动重连、复位、回零或续跑。
