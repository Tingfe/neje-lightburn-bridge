## 出光声明

e 级必须用 **`--laser-output-authorized`**（而不是 `--laser-power-isolated`）—— 因为此时激光**确实是开启的**，声称隔离就是假的。两者互斥，一键入口会自动只给一个：

```sh
python tools/neje.py            # 完整功能 → --laser-output-authorized
```

## 第一步：小功率单段（必须）

**目的**：证明「能出光、且能控住」。

在 LightBurn 里：

| 参数 | 建议值 |
| --- | --- |
| 图稿 | **一条 10mm 直线**（不要图案，方便判读） |
| 功率 | **S = 100（10%，设备 `$30=1000`）** |
| 速度 | 慢一些，例如 **F300（300 mm/min）** |
| 次数 | 1 次 |

按 **Start**。预期：材料上出现**一条淡淡的痕**，位置与设计一致。

**如果出现**：不出光 / 位置不对 / 声音异常 / 机器不按预期停 → **立即断电**，并告诉我。

## ⚠️ 第一次实测暴露的两个坑（2026-10-14）

第一次 e 级实测：出光段 `M4` + `G1 X18S100F6000` 已送达设备、零错误、机器按线运动、跑完停在 `Idle/FS:0,0`。
但**现场速度是 F6000（6000 mm/min = 100 mm/s），而本方案建议 F300** —— 9mm 的线只跑 **0.09 秒**，痕迹极可能浅到看不见。

**请在下一次开始前确认 LightBurn 里这两个设置：**

| 项 | 该确认什么 |
| --- | --- |
| **速度单位** | LightBurn 的速度框可能是 **mm/s** 或 **mm/min**。`F6000` 若来自「6000 mm/min」的默认层速度，就是没改过速度；若是「 mm/s」单位下的数值，换算后会更快 |
| **层速度** | 明确设为 **300 mm/min**（≈ **5 mm/s**）。这是第一次出光最该动的一个参数 |

**另外**：运行期间控制器 `FS:<进给>,<功率>` 里**功率字段恒为 0** —— 该固件不用它上报激光功率，所以**控制器读数无法证明是否出光**，判据只能是现场目视（这与项目的证据分级一致）。
