## 启动故障及修复

第一次USB进程在构造会话时FileNotFoundError退出，只有file_review和error两条日志，没有usb_opened、设备写入或作业提交。原因：ControlledUSBSession先调用固定10mm父类构造，父类立即读取旧的ten-mm-reviewed.gc，随后才覆写为实际文件。E62临时包不包含历史文件，因此默认离线CLI通过仍遗漏了真实构造依赖。该进程失败不计一次运动；保留原日志及启动记录，未重复已发送动作。

最小修复为TenMMUSBSession构造接收已审阅文件，直接使用其wires；ControlledUSBSession显式传入。固定作业仍执行原历史文件散列/命令核验，未授予文件或allow_job时仍拒绝。没有扩大协议白名单、运动范围或自动重发行为。

新增测试在旧文件读取强制抛错时验证变量文件会话可构造、allowed_job恰为该文件且backend.port仍None；同时验证未授权拒绝及固定作业仍读取旧文件。修复前6项局部测试中该项复现失败；修复后**240项完整回归通过，42.039秒**。再建独立Pi目录 `/tmp/neje-xy-e63-20261013`，64份源/文件散列核验及真实构造烟测通过后执行USB。E62旧目录及失败日志保持原样。
