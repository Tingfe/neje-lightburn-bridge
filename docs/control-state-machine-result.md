# E51：作业控制状态机与受限桥接入口

2026-10-12。已把暂停、恢复、停止接入可执行的固定10mm桥接候选，完整177项回归通过，新增34项测试。本轮全部使用离线组件、回环TCP和模拟控制器；没有连接实际设备、运动、出光或发送实际复位。整体完成度由约45%更新为约50%，最终USB等价目标仍未完成。

## 已实现的行为

`ControlledGrblPipeline`沿用已有字节传输及FIFO终端账本，只增加控制状态。普通初始化/固定作业入口默认行为保留；新控制入口需要单独选择，不能从旧的只读或已消费运动授权推导实际执行权限。

| 输入/状态 | 已实现行为 | 验证重点 |
| --- | --- | --- |
| `!` 暂停 | 收到请求即冻结后续普通写入，实时字节优先于普通RX额度和排队查询 | 已预留且正在await的一个载荷可能仍到达设备，不能承诺撤回 |
| 等待暂停 | 发送查询，按实际发送时的控制代次关联报告 | 控制前的旧状态、普通ok、温度消息和Hold:1均不确认暂停；Hold:0或Idle才能确认 |
| `~` 恢复 | 过早的恢复意图等到暂停确认后才发送；收到新的Run/Idle报告后解冻普通写入 | 没有把~本身当作成功或普通行ACK |
| 长时间保持 | 不把正常Hold期间的普通ACK停顿误判为丢失 | 模拟60秒Hold通过；控制过渡及状态查询仍各有8秒上限，缺失会话停止 |
| `0x18` 停止 | 立即禁止继续提交、清空未发送普通行/作业暂存，抛弃后续源文件字节；只尝试一次reset | 同TCP块含非法普通字节时，停止优先；没有重发、自动返程或自动续跑 |
| 实际复位响应 | 收到真实Grbl启动行才将旧pending账本记录为中止，随后新查询确认Idle/Alarm | 旧普通行不生成成功；Alarm原样交付，不解锁、不回零；Idle也不直接证明机械坐标可信 |
| 复位时链路/计数变化 | 锁存未知状态，保留不确定写及清理结果 | 不自动重设NEJE计数、不重新连接、不续发作业 |

`ControlledJobPolicy`仍只接受原已审阅14行10mm零功率文件及固定初始化范围；新增控制字节不开放任意GCode。取消后该实例永久拒绝新作业，必须由后续显式恢复流程建立新会话。

## 接入与验证边界

新增候选参数为`--allow-reviewed-job-controls`，必须同时选择固定10mm候选。默认不执行，离线入口输出在`evidence/control-state-machine/offline-entry.json`。**本轮没有授权或执行这个候选的实际控制。**

在允许TCP源输入前，候选先完成已有位置/设置/模态预检，再读取`$N`并要求`$N0=`、`$N1=`两个启动块均为空；否则不进入可发送作业状态。`$N`尚未在实机授权或读取。这个检查是因为标准GRBL的复位可能执行已保存启动块；不能假设NEJE一定没有启动动作。

控制候选的运行期间只由流水核心接收字节，避免旧的串行完成核验循环阻塞Pause/Stop。正常完成暂只核验真实终端、Idle/X0/Y400/Z0/A0及零速度/零功率，结果明确记录`modal_verified=false`和`rapid_mode_restored=false`。后续需补齐可中断的模态读回及裸G0恢复，不能把这一候选的endpoint标记替代旧作业入口的完整收尾验收。

TCP关闭后仍不追加新的业务/控制写入。如果停止请求尚未实际发送而连接已经关闭，清理记录保留`unsent_urgent_hex`及不确定终点，不能称为设备停止成功。作业已进入控制器缓冲区的动作也不能靠清理本机队列撤回；实际断连行为仍需现场验证。

## 开源依据与采用方式

采用既有GRBL流控账本，控制语义依据[GRBL官方实时命令文档](https://github.com/gnea/grbl/wiki/Grbl-v1.1-Commands)：!和~属于不带普通行ACK的实时控制；暂停保留控制器缓冲，复位可令运动中的位置失去可信性。官方文档及源散列已归档。

参考[cncjs的GRBL控制器实现](https://github.com/cncjs/cncjs/blob/747ffcd5f208ad6556846196d12845c6e6a7fb72/src/server/controllers/Grbl/GrblController.js)的工作流停止与实时控制分离思路，沿用项目既有固定提交快照`evidence/stream-transport/cncjs-GrblController.js`。本次没有复制整套控制器，也没有把其固定延时视为NEJE实测。这里用真实状态报告作为暂停/恢复确认依据。具体已固定提交以`sources.json`为准。
