## 原生工程与实际导出

在 LightBurn Pro 2.0.05 中打开 E61 已验证零功率工程，仅在内存中替换图形，通过 SVG 原生导入一个带5mm进出线的直径10mm圆形；中心置于 X5/Y395，另存新工程 curve-lead-native.lbrn2。重新打开工程，仍有一个图形，边界 X0–10/Y390–400；再次原生导出的 curve-lead-reopened.gc 与首次 curve-lead-native.gc 逐字节相同。原 E61 文件未覆盖。

导出文件 SHA-256：`8c6b7397a75825180d278b4c3bf86251a32e67173e21a9a2e3aacd4eac9a437d`。1535文件字节，78条有效命令，1256作业线字节（包含命令尾部原有ASCII注释；纯注释行按已有规则忽略）。实际路径从(0,400)经5mm进线到(5,400)，沿圆周回到(5,400)，经5mm退线回到(0,400)。Z/A不变。

**实际导出为64段圆周G1短直线加两段进出线，共66段有位移G1，没有G2/G3，没有移动G0。** 因此使用已有 xy-linear-zero 审阅范围，无需扩大白名单。长度41.407266985mm，F60，名义41.407秒；不含加减速及通信。M4 S0，前后M5/S0，无气辅、回零、设置写入或复位。该结果支持当前配置的折线化曲线兼容，不能代替控制器G2/G3圆弧验收。

C00原生层参数为速度1mm/s、两项功率均0%，一个Path图形含四段Bezier和两段直线。工程继承的旧Notes文字仍写着旧候选未验证，该文字不作当前结论；本报告及原生导出对照为准。未改写原生GCode来满足审阅。

原生文件通过现有USB和真实回环TCP+NEJE分帧BLE模拟入口，分别经独立捕获审计通过：两路均78条作业真实模拟终端响应、3条私有收尾，提交的1256字节与源文件逐字节一致；没有伪造成功响应或重放。BLE模拟way=0、未消耗通知尾部0、清理未知false，USB模拟端口关闭。

模拟器验证协议、入队、字节和状态机，不模拟真实时间、机械插补、控制器规划或设备性能。本轮未修改工具或测试源代码，未重跑完整回归；最近全量仍E63的240项通过。本轮临时归档脚本曾发生bytes/Decimal序列化及rapid_segments类型处理错误，均发生在离线数据整理，修正后文件审阅及两路审计完成；不涉及设备动作。
