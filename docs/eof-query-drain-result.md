## 实现边界

正常TCP EOF且输入完整时，停止消费排队命令。如果当前正在执行`status`，仅给已经开始的这条`?`最多2秒完成真实响应/字节计数核验及关闭；不会启动新的排队空行、初始化或运动。EOF后的实际响应保留日志，记录`job_tcp_delivery_suppressed`，不向已退出客户端补写、更不伪造ok。超时后取消、保留不确定写状态，不重试。输入不完整/非法、在途运动、其他异常保持立即停止与原清理行为。

`job_eof_query_drain_finished`表示当前查询与通道清理均已结束；它不是下一次连接或自动续跑授权。单连接消费约束保持。
